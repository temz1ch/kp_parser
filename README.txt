Все лавры Дипсику

Парсер работает на Python 3.15
Используется неофициальный API Кинопоиска
Запросы производятся после ввода токена, токен можно получить в телеграм-боте (tg --> @kinopoiskdev_bot --> /start)

Инструкция по эксплуатации:
0. Запуск .exe файла
1. Ввод названия страны с правильным указанием регистров, дефисов и пробелов ("Босния и Герцеговина"/"Россия"/"США"/и т.д.)
2. Ввод года, с которого будет начинаться период производимого поиска
3. Ввод года, с которого будет заканчиваться период производимого поиска
4. Ввод числа фильмов, поиск которых будет производиться за каждый год (максимальное - 250; отбор происходит по критерию от самых популярных)
5. Ввод токена
6. Скрипт сохраняет собранные данные в отдельный .xmls файл в ту же папку, в которой находится kinopoisk_parser.exe
